# ADDA — Onlayn Təhsil Kursları

Adda təhsil mərkəzinin onlayn kurs platforması.

## Stack
- Frontend: HTML / CSS / JS (static)
- Hosting: Vercel
- Database: Neon (PostgreSQL)

## Lokalda işə salmaq
İstənilən statik server kifayətdir, məsələn:
\`\`\`
npx serve .
\`\`\`

## Deploy
`main` branch-a push edildikdə Vercel avtomatik deploy edir.
